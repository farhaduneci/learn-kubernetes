# Learn Kubernetes

My Kubernetes/CKAD learning track — lessons toward the CKAD (Certified Kubernetes Application Developer) certification.

## Structure

- `MISSION.md` — the "why," success criteria, and constraints for this learning track
- `NOTES.md` — running notes on environment setup and teaching-style preferences
- `RESOURCES.md` — curated knowledge sources and community links, tracked as they're vetted
- `lessons/` — individual lesson pages (HTML), one per topic
- `reference/` — standalone reference material (e.g. architecture deep-dives)
- `learning-records/` — session/progress logs
- `assets/` — shared JS/CSS for the lesson site (table of contents, quiz engine, styling)

## Approach

Curriculum follows the [CNCF CKAD domain breakdown](https://github.com/cncf/curriculum/tree/master/ckad). Practice stays local — no cloud spend: **minikube** for Kubernetes, **LocalStack** for AWS fundamentals (EKS context) taught just-in-time. See `MISSION.md` for full scope and constraints.
